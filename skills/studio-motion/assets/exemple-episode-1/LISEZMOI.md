# Exemple complet : « ChatGPT n'est pas l'IA », épisode 1

Vidéo de 24 s montée avec Studio Motion, style Explicatif, charte #04529A / blanc / noir. Créateur : Mame Bou Fall.

| Fichier | Rôle |
|---|---|
| `spec.js` | Le montage : prise, corrections de sous-titres, 7 animations branchées, sons, nettoyage de la voix |
| `style-explicatif.json` | Le style utilisé |
| `lib.js` | La boîte à outils des animations |
| `textes.js` | **Tous les textes des animations**, à modifier ici, puis `scripts/refaire_animations.sh` |
| `a-tele.html` | « cette télévision… du courant électrique » : la télé s'allume par le câble |
| `b-pas-pareil.html` | « est-ce que la télé est le courant ? Bien sûr que non » : « = ? » barré en « ≠ » |
| `c-chatgpt-ia.html` | « ChatGPT utilise l'IA pour fonctionner » : le produit branché sur la technologie |
| `d-ensemble.html` | « ChatGPT n'est pas l'IA dans son ensemble » : une case parmi 12 domaines |
| `e-question.html` | « Alors, c'est quoi l'IA, exactement ? » : réseau de neurones et question |
| `f-presentation.html` | « Moi c'est Mame Bou Fall, ingénieur… » : carte de présentation |
| `g-signature.html` | « Xam, Jëf, Jariñu » dit face caméra, animé mot par mot |
| `g-signature-plein-ecran.html` | La première version de fin, quand la signature n'était pas encore enregistrée |

Les temps dans `spec.js` sont en secondes de la prise d'origine ; ceux des fichiers HTML en secondes depuis le début de chaque animation.
